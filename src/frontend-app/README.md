# Frontend App

The user interface is the iOS app in `HealthOpsUploader/` (SwiftUI, HealthKit upload, Overview
and Ask tabs, Google Health connection). Build and test instructions are in
[HealthOpsUploader/README.md](HealthOpsUploader/README.md). The API also serves a local debug
page at `GET /debug/assistant` (see `src/api-service/`).
