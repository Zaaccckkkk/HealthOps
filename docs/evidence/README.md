# Evidence index

Start with [the V100 model evaluation](v100-live-evaluation-20261102.md) for the latest reported
fixed-set results, and [portfolio migration verification](portfolio-migration.md) for local checks
performed in this repository. These are different kinds of evidence: migration tests use scripted
models; the earlier V100 evaluation used real Qwen inference.

The remaining dated reports preserve upstream development history, including earlier failures.
Resource project IDs and service URLs may be replaced with placeholders for publication;
reported counts, model digests, rubric and failure descriptions are retained. Raw outputs,
credentials and the exact cohort freeze artifacts remain local, not part of this repository.
Earlier deployment descriptions are historical observations, not promises of a running service.
